# Google Workspace Utilitaires d'administration pas à pas

> bientôt disponible

**Bientôt disponible.**

Ce dépôt prépare un nouvel outil de la suite « pas à pas » de Johan TIDAS. Le développement
est en cours ; en attendant, vous pouvez :

- consulter la [feuille de route](#feuille-de-route) ci-dessous ;
- regarder les deux premiers outils de la suite déjà disponibles :
  [`video-pas-a-pas`](https://github.com/jtid972/video-pas-a-pas) et
  [`compression-pas-a-pas`](https://github.com/jtid972/compression-pas-a-pas).

Ce futur outil s'intéresse en priorité à outiller l'administration courante d'un domaine Google Workspace (utilisateurs, groupes, Drive partagés) via les API Google Admin.
